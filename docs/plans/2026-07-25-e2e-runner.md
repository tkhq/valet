# Unified e2e entrypoint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make e2e` — one runner (`scripts/e2e.ts`) that loads `.env.e2e`, probes prerequisites, runs every suite in the spec's 25-row scorecard as child processes, and prints a ✓/✗/⊘ scorecard (spec: `docs/specs/2026-07-25-e2e-runner-design.md`).

**Architecture:** A pure "step table + probes + scorecard" library (`scripts/e2e/lib.ts`, unit-tested) and a thin executor (`scripts/e2e.ts`) that spawns each armed step. New test code: `smoke-orchestrator.ts`, `dogfood.ts`→`smoke-session.ts` rename, `fullstack-scenario.ts` shared driver (docker + k8s variants), `oidc-keycloak.e2e.test.ts`.

**Tech Stack:** tsx, node child_process, vitest (for lib tests + the keycloak test), existing Make targets.

## Global Constraints

- No `any`, no `as unknown as`, no `@ts-ignore` (CLAUDE.md).
- **Every kubectl/helm invocation pins `--context rancher-desktop`** (`--kube-context` for helm). Never the ambient context.
- The runner must never set `CI` (several docker suites self-skip on it).
- The runner never prints secret values — only variable names.
- Exit nonzero iff an armed step failed; skipped steps never fail the run.
- Node 22 for all test runs.
- Commit per task, terse messages, no AI co-author trailers.

**Interfaces (Produces):**

```ts
export type Need = "key" | "docker" | "k8sContext" | "e2eK8sOptIn" | "telegram" | "githubLive" | "openai";
export interface StepDef {
  id: string;
  group: "static" | "integration" | "docker" | "fullstack" | "live";
  title: string;
  command: string[];            // argv, spawned without shell
  cwd?: string;                 // default repo root
  needs: Need[];
  env?: Record<string, string>; // extra env (e.g. VALET_CLI_E2E: "1")
  scrubKeys?: boolean;          // integration-core: remove key vars from child env
  timeoutMs: number;
}
export interface Probes { key: boolean; docker: boolean; k8sContext: boolean; e2eK8sOptIn: boolean; telegram: boolean; githubLive: boolean; openai: boolean; }
export const STEPS: StepDef[];
export function missingNeeds(step: StepDef, probes: Probes): Need[];               // [] = armed
export function needHint(n: Need): string;                                          // "set ANTHROPIC_API_KEY", "Docker daemon not reachable", …
export function parseEnvFile(content: string): Record<string, string>;              // KEY=VALUE lines, # comments, throws on malformed lines
export interface StepResult { id: string; status: "passed" | "failed" | "skipped"; durationMs: number; skipReason?: string; }
export function renderScorecard(results: StepResult[]): string;                     // human table w/ ✓ ✗ ⊘ + totals
export function toJsonReport(results: StepResult[]): { steps: StepResult[]; passed: number; failed: number; skipped: number; exitCode: number };
export function selectSteps(all: StepDef[], only?: string[]): StepDef[];            // --only filter, throws on unknown id
```
