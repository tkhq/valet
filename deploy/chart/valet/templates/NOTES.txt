Visit https://{{ .Values.ingress.host }}/ (accept the self-signed certificate
if you haven't configured a real one via ingress.tls.secretName).

If {{ .Values.ingress.host }} doesn't resolve, add it to /etc/hosts pointing
at your ingress controller's address, or switch ingress.host to a
*.sslip.io name in values.
{{- else }}
Ingress is disabled; port-forward the api Service to reach it:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "valet.fullname" . }}-api 8787:{{ .Values.service.port }}
{{- end }}

{{- if .Values.api.auth.adminEmails }}
Administrators ({{ .Values.api.auth.adminEmails }}) become org admins when
they sign in with SSO, or with Google/GitHub and a verified email.
{{- else }}
No api.auth.adminEmails set. Without SSO, create the first admin with the
one-time link in the api log (a sign-up without it gets no admin role):
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "valet.fullname" . }}-api | grep "No admin yet"
With SSO on, the api refuses to boot until api.auth.adminEmails names an admin.
{{- end }}
