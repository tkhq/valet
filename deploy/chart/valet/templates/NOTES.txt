Valet has been deployed.

{{- if .Values.ingress.enabled }}
Visit https://{{ .Values.ingress.host }}/ (accept the self-signed certificate
if you haven't configured a real one via ingress.tls.secretName).

If {{ .Values.ingress.host }} doesn't resolve, add it to /etc/hosts pointing
at your ingress controller's address, or switch ingress.host to a
*.sslip.io name in values.
{{- else }}
Ingress is disabled; port-forward the api Service to reach it:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "valet.fullname" . }}-api 8787:{{ .Values.service.port }}
{{- end }}

Create the first admin with the one-time link in the api log. A sign-up
without it is refused, so a stranger cannot claim the deployment:
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "valet.fullname" . }}-api | grep "No users yet"
The link works once and changes on every api restart until someone uses it.
To name admins in advance instead, set org.members with role: admin in the
instance config.

Reminder: this chart does NOT install the agent-sandbox CRDs/controller.
See deploy/chart/valet/README.md for install ordering.
