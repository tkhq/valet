A slide deck. Each slide is a top-level `<section>` authored on a fixed 1920x1080 stage — the canvas scales it to fit, so use absolute px sizes (titles 64-120px, body 28-40px, mono 24-28px). Give every section a `data-label` (short name shown in the slide strip) and `data-speaker-notes` (what the presenter says). One idea per slide, large type, minimal text; content must fit the 1080px height or it gets clipped.
